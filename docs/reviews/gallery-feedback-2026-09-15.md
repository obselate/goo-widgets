## Public API changes

- Goo adds `PointerEvent.IsFromInteractiveChild`, relative to each handler's routed path. The same internal clickable/focusable predicate is used by native titlebar hit testing. Core commit: `8c7d4d9`.
- Widgets add `TreeViewInput.ExpandOnActivate` (default false), `MenuInput.Placement` (default BottomStart), and nullable `MenuInput.SubmenuPlacement` (default RightStart). No public member was removed.
- The review widgets still target Goo `0.5.4-preview.1`; the private review cache and lock hashes contain the new event property. Published packages are unchanged.
